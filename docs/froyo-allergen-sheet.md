# Froyo Foundry Allergen Sheet

*Applies to all Froyo Foundry locations. Last updated: October 2026.*

This sheet lists which of the 9 major food allergens (milk, eggs, fish, shellfish, tree nuts, peanuts, wheat, soy, and sesame) are ingredients in each flavor, topping, and cone.

## Cross-contact warning

Our kitchens handle milk, eggs, tree nuts, peanuts, wheat, and soy. All flavors and toppings are made and served on shared equipment, so we cannot guarantee that any item is free of any allergen. Fish, shellfish, and sesame are not used in any Froyo Foundry product. If you have a severe food allergy, please talk with a team member before ordering.

## Dietary quick reference

- **Vegan flavors:** Berry Blockchain Blast, Aicai Bowl.
- **Dairy-free flavors:** Berry Blockchain Blast, Aicai Bowl.
- **Flavors made without gluten ingredients:** Mint Condition, Berry Blockchain Blast, Recursive Raspberry, Vanilla Exception, Null Pointer Pistachio, Java Jolt, Peanut Butter Protocol, Cloud Caramel Cache, Aicai Bowl. Cups are made without gluten ingredients; waffle cones contain wheat.
- **Flavors without peanuts or tree nuts as ingredients:** Mint Condition, Berry Blockchain Blast, Cookie Container, Recursive Raspberry, Vanilla Exception, Java Jolt, Cloud Caramel Cache, Aicai Bowl.
- **Flavors with nuts:** Null Pointer Pistachio contains tree nuts (pistachios). Peanut Butter Protocol contains peanuts.
- **Caffeine:** Java Jolt contains caffeine (about 40 mg per Kilobyte).
